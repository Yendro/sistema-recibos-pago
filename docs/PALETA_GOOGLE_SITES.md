# Paleta para Google Sites

Esta paleta mantiene continuidad visual entre Google Sites y la aplicación. El
azul principal se reserva para navegación y acciones; `#379FFF` funciona como
acento puntual para no competir con el color principal.

| Uso | Color | Aplicación recomendada |
| --- | --- | --- |
| Azul principal | `#0B57D0` | Navegación activa, enlaces y botones principales |
| Azul principal oscuro | `#0842A0` | Estados presionados y elementos de énfasis |
| Azul de acento | `#379FFF` | Detalles decorativos, ilustraciones e indicadores puntuales |
| Contenedor azul | `#D3E3FD` | Fondos de navegación seleccionada y botones tonales |
| Texto sobre contenedor azul | `#041E49` | Texto e iconos sobre `#D3E3FD` |
| Fondo general | `#F7F9FC` | Fondo de páginas y secciones amplias |
| Superficie | `#FFFFFF` | Tarjetas, formularios y encabezado |
| Superficie alternativa | `#F0F4F9` | Secciones informativas y encabezados de tablas |
| Texto principal | `#1F1F1F` | Títulos, cifras y contenido principal |
| Texto secundario | `#444746` | Ayudas, etiquetas y metadatos |
| Borde suave | `#C4C7C5` | Divisores, tarjetas y contornos discretos |
| Correcto | `#0F6B3D` | Confirmaciones y estados completados |
| Error | `#B3261E` | Errores y acciones destructivas |

## Configuración sugerida

- Tema claro de Google Sites.
- Fondo principal `#F7F9FC`.
- Encabezado y bloques de contenido `#FFFFFF`.
- Navegación, enlaces y botones destacados `#0B57D0`.
- Fondos de selección o secciones destacadas `#D3E3FD` con texto `#041E49`.
- `#379FFF` únicamente en detalles decorativos para conservar una jerarquía
  visual clara.
