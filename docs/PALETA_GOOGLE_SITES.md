# Paleta para Google Sites

Esta paleta adapta la familia **Nautical Blues** para mantener continuidad
visual entre Google Sites y la aplicación. Los tonos más profundos definen la
jerarquía, mientras que el celeste se reserva para selecciones y contenedores.

| Uso | Color | Aplicación recomendada |
| --- | --- | --- |
| Azul abisal | `#00072D` | Texto principal, títulos y contraste máximo |
| Azul marino | `#001C55` | Estados presionados y elementos de énfasis |
| Azul principal | `#0A2472` | Navegación, enlaces y botones principales |
| Azul costero | `#0E6BA8` | Iconos, detalles decorativos y color inicial de recibos |
| Azul cielo | `#A6E1FA` | Navegación seleccionada, avisos y botones tonales |
| Fondo general | `#F4FAFD` | Fondo de páginas y secciones amplias |
| Superficie | `#FFFFFF` | Tarjetas, formularios y encabezado |
| Superficie alternativa | `#E8F5FB` | Secciones informativas y encabezados de tablas |
| Texto secundario | `#40566A` | Ayudas, etiquetas y metadatos |
| Borde suave | `#BFD3DE` | Divisores, tarjetas y contornos discretos |
| Correcto | `#0F6B3D` | Confirmaciones y estados completados |
| Error | `#B3261E` | Errores y acciones destructivas |

## Configuración sugerida

- Tema claro de Google Sites.
- Fondo principal `#F4FAFD`.
- Encabezado y bloques de contenido `#FFFFFF`.
- Navegación, enlaces y botones destacados `#0A2472`.
- Fondos de selección o secciones destacadas `#A6E1FA` con texto `#00072D`.
- Usa `#0E6BA8` en iconos y detalles; reserva `#001C55` para estados de énfasis.
